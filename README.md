# Coleman Storybook

A testimonial capture, story-intelligence, and marketing content library platform. Customer-zero implementation: URJ Camp Coleman.

**Working name.** "Coleman Storybook" is a configurable default, not a final product name.

This project is in **Phase 0 (Product & Brand Foundation)**, just completed. See `docs/phase-status.md` for the full phase tracker and `docs/product-vision.md` for the product thesis, scope, and success criteria.
